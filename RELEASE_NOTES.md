First public release of Goaty Loops for Windows 10 and 11.

**Download** `goaty-loops.exe` below, put it in a folder you own (e.g. `Documents\Goaty Loops`) and run it. No installer needed. SmartScreen may warn because builds aren't code-signed yet: choose *More info → Run anyway*.

### Highlights
- Channel rack, step sequencer, piano roll, playlist and a 127-insert mixer with sends, sidechain and plugin delay compensation
- VST3 instruments and effects, built-in synth, drum machine, sampler and effects
- Low-latency audio: Windows shared, low-latency and exclusive (WASAPI) drivers in **Options → Audio settings**
- Opens `.flp` project files for interoperability
- Autosave, crash recovery and crash reports
- In-app updates: future versions install from **Help → Check for updates**
